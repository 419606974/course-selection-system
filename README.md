# course-selection-system

#### 运行说明：

1. 点击 Docker Desktop Installer.exe 安装 docker desktop
2. 点击 start.bat 启动项目，第一次启动会有点久
3. 浏览器打开 http://127.0.0.1:8888/

#### 项目说明：

1. 进入 http://127.0.0.1:8888/ 后，首先是登录页面，其中分为<br/>
   管理员(账号：admin，密码：admin)<br/>
   查询员(账号：chaxun，密码：chaxun)<br/>
   两个角色进行登录，登录时记得 选择角色 登录
   
2. 管理员可进行教师，学生，课程，成绩的添加、修改、删除操作，其中批量上传数据时，请参考批量上传弹出窗口里的表头设置  excel 文件
   
3. 查询员只能进行查询

4. 平均分里的年度和学期是根据添加课程时的 年度 和 学期 进行统计的
5. 分数列均可点击表头排序
